# v1.1.4 draft

- Apply the same host-key policy, timeout and batch authentication to SSH and SSHFS.
- Honor environment > config > default for all main settings, including empty option overrides.
- Continue mounting/unmounting remaining targets after errors and return a failing aggregate exit status.
- Validate host-key policy, timeout, port range and explicit identity files before network use.
- Fix literal tilde expansion, normalize mount paths, reject relative dot components and symlink escapes.
- Reserve explicit mount names before assigning automatic names to avoid skipping targets on collisions.
- Verify SSHFS filesystem type and exact source for status, skipping and unmounting; refuse conflicts.
- Add regression coverage for configuration, validation, operation failures, naming and mount identity to CI.

Mount-source verification requires findmnt; path normalization requires realpath.
Custom fsname/subtype options and differently spelled external mount sources are
reported as conflicts and must be inspected manually. Automated regression tests
mock network/mount operations. A separate real SSHFS integration test also passed
in WSL; see [local validation](local-validation-2026-09-12.md).

## Follow-up simplification and regression review

- Remove unused success counters and remote-path arrays, the unreachable dry-run unmount branch, and redundant validation.
- Read/validate targets once before assigning automatic names; retain explicit-name reservations independent of row order.
- Use shared SSH argument arrays and operation return values instead of duplicated options and global failure counters.
- Capture mkdir errors directly without temporary files; create mount directories only after successful SSH preflight.
- Skip matching existing mounts without requiring the original identity file; report conflicts in dry-run too.
- Parse unmount indices without arithmetic evaluation or glob expansion, deduplicate leading-zero indices, and preserve exact paths containing spaces/commas.
- Treat unreadable configuration/target files as errors instead of successful empty plans.
- Add tests for these cases and preservation/removal of mount directories after failures.

## Final preflight fixes

- Detect a file blocking any parent component, not only a file at the mountpoint.
- Return exit 1 for deterministic local-path errors in dry-run while continuing later targets; perform this check even when FUSE is unavailable.
- Reject explicitly empty BASE_DIR config values unless the environment overrides them.
- Update the script version to 1.1.4 in preparation for release.
- Extend regression coverage for blocked paths, permissions, FUSE/SSH-only hints and empty BASE_DIR precedence.

## SSH policy and binary safety

- Reject StrictHostKeyChecking, ConnectTimeout, BatchMode and ssh_command in global/per-target options, regardless of case; a violation aborts the whole plan before network/mount calls.
- Installation and uninstallation recognize existing flymount releases by their stable header, without executing the file; refuse foreign files, symlinks, directories and special files.
- Install via an atomic replacement, preserving other hard links to an old binary.
- Add policy regression coverage and binary safety tests to CI.
- Repeat real SSHFS mount/read/write/status/unmount validation without ssh_command overrides; all passed with isolated localhost credentials.
