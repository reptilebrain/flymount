## v1.1.3 - 2026-02-23

### Changed
- Improved operational reliability in `flymount.sh`:
  - explicit failure accounting for mount/unmount operations
  - fail-fast behavior in execute mode
  - clearer exit code behavior for invalid-only targets
- Added debug/log separation:
  - `--verbose` / `FLYMOUNT_DEBUG=1` for debug output
  - `--log-file` / `FLYMOUNT_LOG_FILE` for debug file logging
- Added safer cleanup behavior:
  - attempts to remove newly created empty mount directory if mount fails

### Added
- New regression tests:
  - `tests/test_exit_codes.sh`
  - `tests/test_logging_modes.sh`
- CI now runs new tests and shellchecks them.

### Documentation
- Updated `README.md` with:
  - new logging flags
  - exit code contract
- Updated maintainer and contributor guides with new test steps.
